# File Manifest

This repository contains the GitHub distribution of AI Prompt Architect Pro v3.0.
An archived, citable release is available on Zenodo: https://doi.org/10.5281/zenodo.20368438

| File | Purpose |
|---|---|
| `index.html` | Step 1: curriculum selection module and application entry point. |
| `efarmoges_en.html` | Step 2: application type selection module. |
| `prompt_generator_en.html` | Step 3: prompt studio and prompt generation module. |
| `README.md` | General description, setup, usage, citation, and license notes. |
| `CITATION.cff` | Machine-readable citation metadata. |
| `LICENSE` | MIT License (full text). |
| `CHANGELOG.md` | Release notes. |
| `FILE_MANIFEST.md` | This repository file inventory. |

To run the tool, keep the three HTML files in the same directory and open `index.html`
in a modern web browser. No installation or server is required for the core workflow.
