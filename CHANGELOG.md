# Changelog

## v3.1 - 2026-11-07

- Prompt Studio (`prompt_generator_en.html`): added an **AI Model** menu for live execution through the Gemini API, with `gemini-3.8-flash` as the default and `gemini-3.5-flash-lite` as an alternative (replaces the fixed `gemini-2.5-flash-preview-09-2025` model).
- Prompt Studio: added a progress indicator while a response is generated (spinner, "Generating..." button label, and an elapsed-time counter in the chat, announced to screen readers). The Start Generation and Send buttons are disabled during a request to prevent duplicate requests.
- Updated visible interface version labels to v3.1.
- Updated the user manual (`User_Manual_v3.1.html`, distributed with the Zenodo release), README, citation metadata, and file manifest.
- Added a reference to the accompanying design case article (Korakakis, Dalacosta, & Vlassi, in press, *International Journal of Designs for Learning*).
- An archived, citable release of this version is available on Zenodo: https://doi.org/10.5281/zenodo.24040227

## v3.0 - 2026-05-24

- Published the v3.0 GitHub distribution of AI Prompt Architect Pro.
- Updated visible interface version labels from v2.0 to v3.0.
- Used `index.html` as the application entry file (curriculum selection module); the three HTML modules communicate through browser `localStorage` and must stay in the same folder.
- Updated README, citation metadata, license statement (MIT), and file manifest.
- An archived, citable release of this version is available on Zenodo: https://doi.org/10.5281/zenodo.20368438
